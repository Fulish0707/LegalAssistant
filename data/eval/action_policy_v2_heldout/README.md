# 행동 정책 v2 보류 평가 (사전 등록)

작성: 2026-11-19. 구조화된 판정(사실 선택지 + 법률 요소 체크리스트)을 구현하기 전에, 어떤 모델도 이 사례로 실행하기 전에 고정한다. 결과를 본 뒤 사례·기대 행동·지표를 바꾸지 않는다. 바꿀 일이 생기면 맨 아래 변경 기록에 이유와 함께 적고, 바꾼 뒤의 결과는 보류 평가로 보고하지 않는다.

## 목적

새 판정 구조가 EXAONE 3.5(7.8B)에서 다음을 해내는지, 현재 코드와 같은 조건으로 비교한다.

1. 법률 근거가 부족하거나 사실이 미확인·충돌일 때 답하지 않는가(가장 중요).
2. 근거와 사실이 갖춰졌을 때 답하는가. 이전 보류 세트에는 이런 공제 사례가 없었다.
3. 판정 무효가 줄었는가.

## 입력

- 법령 3개: `action_policy_pilot`과 같은 공식 원문 파일.
- 판례 창 4개: 모두 **가상 판결문**(`case-90001.txt`, `case-90002.txt`)에서 뽑았다. `case-rule`(판단 1문단: 합의 종료 뒤 차임 의무), `case-finding`(판단 2문단: 특약 적용 범위와 결론), `case-claim`(임대인 측 주장), `case-unknown`(제목 없는 요지, 이 세트에서는 쓰지 않음). `case-rule`만 이 세트에서 새로 추가했다.
- 계약서·합의 메모·문자 기록은 모두 가상 문서이고, 이전 세트와 문구가 다르다.
- 기대 행동은 사람이 정한 행동 라벨이며 법률 결론이 아니다. 사람의 법률 검토는 없다.

| 사례 | 사실 | 첫 근거 → 추가 근거 | 기대 행동 |
|---|---|---|---|
| V1 | 합의 있음(사용자 진술) | 판단 1·2문단, 618 → 105 | answer |
| V2 | 합의 있음(사용자 진술) | 618 → 판단 1·2문단 | research → answer |
| V3 | 합의 없음(사용자 진술) | 618 → 105 | research → withhold |
| V4 | 진술 없음 | 판단 1·2문단, 618 → 105 | clarify |
| V5 | 합의 있음(첨부 메모에만) | 판단 1·2문단, 618 → 105 | answer |
| V6 | 진술(합의)과 첨부 문자(거절) 충돌 | 판단 1·2문단, 618 → 105 | clarify |
| V7 | 합의 있음(사용자 진술) | 임대인 주장, 618 → 105 | research → withhold |
| V8 | 조항 일반 설명 | 주임법 10, 민법 105 → 없음 | answer |
| V9 | 조항 일반 설명 | 618 → 없음 | research → withhold |
| V10 | 정책 꺼짐(대조) | 주임법 10 | 기본 경로 answer |

## 해석 기준

- 표본이 작다(10사례 × 3회). 비율은 기술 통계로만 쓴다.
