# 답변 작성 단계 비교 (사전 등록)

작성: 2026-11-20, 모델 실행 전. 결과를 본 뒤 이 파일의 기준을 바꾸지 않는다. 바꾸면 맨 아래 변경 기록에 이유와 함께 추가한다.
기준 초안 합의: 선생님 결정 3건(준비물·주의점은 근거 판결문과 대조해 맞으면 정답, 근거에 없으면 해당 없음 / 임대차 외 분야 포함 / 선생님 표본 확인은 평가 후 검토).

## 목적

정책이 "답변"을 고른 뒤 근거로 상담 답변을 쓰는 단계에서, 법률 QLoRA 어댑터(Qwen3-4B 기반)가 현재 서빙 모델(EXAONE 3.5 7.8B)보다 나은지, 어댑터가 원본 대비 무엇을 바꾸는지 본다. 정책·검색은 거치지 않고 답변 작성 단계만 직접 호출한다(임대차 외 분야는 정책 쟁점 정의가 아직 없어서).

## 갈래

| 이름 | 모델 | 출력 방식 |
|---|---|---|
| G1 현재 | exaone3.5:7.8b | 구조화 JSON, 운영 답변 프롬프트 |
| G2 원본 | qwen3-4b-base:q8_0 | plain_text, 어댑터 학습 형식 그대로 |
| G3 어댑터 | qwen3-4b-legal:q8_0 | plain_text, 어댑터 학습 형식 그대로 |
| G3s 보조 | qwen3-4b-legal:q8_0 | 구조화 JSON(형식 제약을 견디는지 확인) |

- G2·G3는 같은 Q8_0 양자화·같은 비사고(non-thinking) 템플릿·같은 학습 형식 프롬프트(`training.dataset.SYSTEM` + `adapter_eval.retrieved_messages`)라서 차이가 어댑터에서 온다. 병합 검증은 spikes/002(chrF 0.80 대 원본 0.35)에서 이미 했다.
- G1은 운영 설정 그대로(구조화 스키마, 운영 프롬프트). 형식이 다른 것은 갈래의 본질이라 한계로 적는다.
- 공통: temperature 0.2, max_tokens 2048(운영 기본값), num_ctx 12288(local 설정), timeout 300초. 모델별 2회 반복, 단일 GPU 순차 실행.

## 입력

- 사례 12개: 임대차 4(L1~L4), 민사 3(C1~C3), 형사 3(X1~X3), 행정 2(A1~A2). 모두 정책이 answer를 고르는 상황(사실·근거가 갖춰진 상태). 사용자 상황은 질문 문장에 넣어 모든 갈래에 동일하게 준다.
- 법령 20개 조문: 국가법령정보 공식 API 코퍼스(`data/api_laws/statute-api-full`, statute-api-full-v1)에서 조문 단위 그대로 추출. 출처 URL·시행일·코퍼스 파일·sha256을 sources.json에 기록. 민법 105·618조는 action_policy_pilot의 공식 추출을 재사용.
- 판결문 12개: **전부 가상 판결문**(`실제 판례가 아님` 표시). 근거 창은 "3. 판단" 섹션 원문(제목 없는 창). 러너는 표시 없는 판례 파일을 거부한다.
- 대조표(`comparison.json`): 사례마다 제공 근거에서 뽑은 핵심 법리·준비물·주의점. **모델 실행 전에 이 빌드 스크립트로 고정한다.** 근거에서 도출할 수 없는 항목은 넣지 않는다(이번 세트는 모두 근거에서 도출 가능).

## 자동 지표 (스크립트 판정)

- A1 인용 검증 통과율: 운영 `Verifier`가 ok인 답변 비율.
- A2 근거 밖 인용(치명): 제공하지 않은 조문·사건번호를 쓴 답변 수(`statute_not_in_evidence`, `case_not_in_evidence`). **1건이라도 있으면 그 답변은 치명 실패.**
- A3 지연(elapsed_ms 중앙값)과 본문 길이.
- 생성 실패(스키마 오류·타임아웃)는 별도 집계하고 갈래 비교에서 제외하지 않는다(실패도 비용이다).

## 블라인드 채점 (C1~C6)

채점자에게는 답변 본문과 그 답변이 본 근거(법령 원문+판결 창), 사용자 질문, 대조표만 준다. 갈래·모델·반복 번호는 `_key`로 분리하고 고정 시드로 섞는다. citations·confidence 등 코드가 붙인 필드는 본문에서 뺀다.

- C1 상황 반영 (맞음/틀림): 사용자의 구체적 사실을 정확히 짚고 그 사실에 맞춰 설명하는가. 사실을 바꾸거나 없는 사실을 만들면 틀림.
- C2 법리 정확성 (맞음/틀림): 법률 설명이 대조표의 핵심 법리와 맞는가. 근거에 없는 법리를 단정하면 틀림. 근거와 무관한 준비물·주의점을 단정적으로 지어내도 틀림.
- C3 준비물 (맞음/틀림/해당 없음): 대조표에 준비물이 있으면 그중 하나 이상을 제시하고 근거와 어긋나는 준비물을 만들지 않으면 맞음. 대조표가 해당 없음이면 채점하지 않는다.
- C4 주의점 (맞음/틀림/해당 없음): C3와 같은 방식.
- C5 단정 회피 (맞음/틀림): 사용자 사건의 결과를 조건 없이 확정하지 않는가. 근거에 근거한 조건부 결론, 사건마다 다를 수 있음·확인 필요를 밝히면 맞음.
- C6 읽기 쉬움 (0/1/2): 법률 지식이 없는 사람이 다음 행동을 알 수 있는가. 유일한 점수형 항목.

합계 점수 대신 항목별 맞음 비율(해당 없음 제외)로 비교한다. 채점자는 AI 1명(한계로 공개), 불일치·애매 항목은 열쇠 대응 전후로 주된 결론이 바뀌는지 검사한다.

## 해석 기준

- A2 치명 실패가 G1보다 많으면 다른 점수와 무관하게 G3를 채택하지 않는다.
- 주 비교: G3 대 G1의 C1~C4 맞음 비율. 보조: G3 대 G2(어댑터 효과), G3s(형식 제약 내구성).
- 표본이 작다(갈래당 12사례 × 2회). 비율은 기술 통계로만 쓰고 일반화하지 않는다.
- 사람의 법률 검토는 없다. 가상 판결문의 법리를 옳다고 전제하지 않으며, 대조표는 근거 문서와의 일치만 본다.
- 형식 차이(구조화 vs plain)가 C6에 영향을 줄 수 있다. 갈래 간 C6 비교는 참고로만 본다.
