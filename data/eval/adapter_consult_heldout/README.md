# 상담형 추가 학습 어댑터 채택 확인 — 보류 평가 (사전 등록)

작성: 2026-11-20, 모델 실행 전. 결과를 본 뒤 기준을 바꾸지 않는다.

## 배경

기존 법률 어댑터(qwen3-4b-legal, 짧은 문답 학습)는 답변 작성 비교에서 EXAONE보다 모든 블라인드 항목이 낮았다(`../answer_generation/RESULTS.md`).
8GB GPU에서 bge-m3·리랭커와 함께 상주하려면 4B급 답변 모델이 필요하므로, 같은 어댑터를 상담 형식(운영 LegalAnswer JSON, 판결문 근거 준비물·주의점)으로 300건 추가 학습했다
(`data/training/consult-sft-v1`, `scripts/build_consult_sft.py`, `scripts/train_consult_sft.py`). 학습 데이터는 로컬 Qwen3-8B 추출 + 코드 필터이며 사람 법률 검토는 없다.

## 입력

- 새 사례 8개: 임대차 2(VL1 묵시적 갱신 해지, VL2 상가 갱신요구 거절), 민사 2(VC1 시효 중단, VC2 공작물 책임), 형사 2(VX1 모욕, VX2 점유이탈물횡령), 행정 2(VA1 이유 제시, VA2 행정심판 임의적 전치).
- 법령 12개 조문(공식 API 코퍼스): 주택임대차보호법 6·6의2, 상가건물 임대차보호법 10, 민법 162·168·178·758, 형법 311·312·360, 행정절차법 23, 행정소송법 18. 이전 세 세트와 겹치는 조문이 없음을 빌더가 검사한다.
- 판결문 8개: 전부 가상(`실제 판례가 아님`), 근거 창은 판단 섹션.
- 대조표: 모델 실행 전 `scripts/build_adapter_heldout.py`로 고정.

## 갈래·실행

- **E**: `exaone3.5:7.8b` (현재 서빙 기준, Q4_K_M).
- **A0**: `qwen3-4b-legal:q8_0` (기존 어댑터 병합본).
- **A1**: `qwen3-4b-consult:q8_0` (추가 학습 어댑터 병합본, 같은 Q8_0 변환·같은 비사고 템플릿). epoch은 검증 손실(학습 데이터의 별도 30건)이 가장 낮은 것을 쓴다. 이 세트의 결과로 epoch을 고르지 않는다.
- 셋 다 구조화 갈래, 현재 운영 프롬프트, 운영 설정(temperature 0.2, max_tokens 2048, num_ctx 12288, timeout 300초). 사례당 2회, 단일 GPU 순차. 학습·병합과 동시에 돌리지 않는다.

## 지표·채점

이전 평가와 동일: A1(완료)/A2(근거 밖 조문·사건번호 = 치명)/A3(인용 검증) + C1~C6(`../answer_generation/GUIDELINES.md`, 대조표 대조).
48건 혼합 셔플(시드 20261124), 채점자 4명 × 12건, 블라인드(모델명·갈래 비공개). 대조표가 비어 있지 않으면 '해당 없음' 무효.

## 게이트

### 판정 1 — A1이 A0를 대체하는가 (4B 후보 교체). 전부 통과해야 한다.

- **H1 주효과:** C3 맞음 비율 A1 > A0, C4 A1 ≥ A0. (각 n=16)
- **H2 회귀:** C1·C2·C5 각각 A1 맞음 수 ≥ A0 − 2.
- **H3 안전:** A2 치명 A1 ≤ A0, 인용 검증 실패 A1 ≤ A0, 완료 A1 ≥ A0.

### 판정 2 — A1이 EXAONE급인가 (서빙 교체 후보). 판정 1 통과 시에만 본다. 전부 통과해야 한다.

- **Q1:** C1~C5 각각 A1 맞음 수 ≥ E − 2.
- **Q2:** A2 치명 A1 ≤ E, 인용 검증 실패 A1 ≤ E.

판정 2를 통과해도 곧바로 서빙을 바꾸지 않는다. Q4_K_M 재양자화 패리티와 전체 파이프라인 공존 메모리 측정이 남는다.
판정 2 실패면 EXAONE을 유지한다.

## 해석·한계

갈래당 16건 기술 통계. 사람 법률 검토 없음. 가상 판결문 법리를 정답으로 간주. 채점자는 같은 계열 AI 4명.
애매 항목 전부 뒤집기 민감도를 함께 보고한다. 학습 데이터 정답의 핵심(reference answer)은 기존 어댑터가 이미 학습한 문장이라
검증 손실은 형식 학습의 대략적 신호일 뿐이다. 이 세트도 결과를 보면 소진된다.
