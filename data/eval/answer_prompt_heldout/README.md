- 법령 11개 조문: 공식 API 코퍼스에서 새로 추출(민법 646·629·580·582·766, 형법 307·310·355·356, 행정심판법 27, 정보공개법 9). 출처·해시 기록.

- 대조표(`comparison.json`): 모델 실행 전 빌드 스크립트로 고정.

## 갈래·실행

## 채택 게이트 (전부 통과해야 채택)
