# 행동 정책 v3 보류 평가 (사전 등록)

작성: 2026-11-19. v3 판정(요소를 내용으로 묻기, 이유와 선택 분리)을 구현하기 전에, 어떤 모델도 이 사례로 실행하기 전에 고정한다. 결과를 본 뒤 사례·기대 행동·지표를 바꾸지 않는다. 바꿀 일이 생기면 맨 아래 변경 기록에 적고, 바꾼 뒤의 결과는 보류 평가로 보고하지 않는다. 구현 중 디버깅에는 이전 세트(`action_policy_pilot`, `action_policy_pilot_heldout`, `action_policy_v2_heldout`)만 쓴다.

## 목적

v2 보류 평가(`../action_policy_v2_heldout/RESULTS.md`)에서 EXAONE은 위험한 답변이 0이었지만 공제 사례에서 한 번도 답하지 못했고, 이미 진술한 사실을 되물었다. v3가 위험한 답변 0을 유지하면서 이 두 가지를 줄이는지 본다.

## 입력

- 법령 3개: 이전 세트와 같은 공식 원문 파일.
- 가상 판결문 3개. 모두 **실제 판례가 아니다**. `case-90003.txt`는 이 세트에서 새로 썼다. 합의 없이 일방 퇴거한 경우 차임 의무가 계속되고 조기 퇴거 특약이 적용된다는 내용이다. 이전 세트에 없던 "합의 없음 + 근거 충분" 사례를 만들기 위한 것이다.
- 계약서·문자 기록·메모는 모두 가상 문서이고, 이전 세트와 문구가 다르다.
- 기대 행동은 사람이 정한 행동 라벨이며 법률 결론이 아니다. 사람의 법률 검토는 없다.

| 사례 | 사실 | 첫 근거 → 추가 근거 | 기대 행동 |
|---|---|---|---|
| W1 | 합의 있음(사용자 진술, 새 표현) | 90001 판단 1·2문단, 618 → 105 | answer |
| W2 | 합의 없음(사용자 진술) | 90003 판단 1·2문단, 618 → 105 | answer |
| W3 | 합의 없음(사용자 진술) | 618 → 105 | research → withhold |
| W4 | 진술 없음 | 90003 판단 1·2문단, 90001 판단 1문단, 618 → 105 | clarify |
| W5 | 합의 있음(첨부 문자 기록에만) | 90001 판단 1·2문단, 618 → 105 | answer |
| W6 | 진술(합의 없음)과 첨부 메모(합의) 충돌 | 두 판결 판단 문단, 618 → 105 | clarify |
| W7 | 합의 있음(사용자 진술) | 90001 주장, 618 → 90001 판단 1문단 | research → withhold |
| W8 | 합의 없음(사용자 진술) | 90003 주장, 618 → 105 | research → withhold |
| W9 | 조항 일반 설명 | 민법 105, 주임법 10 → 없음 | answer |
| W10 | 조항 일반 설명 | 90003 주장 → 없음 | research → withhold |
| W11 | 정책 꺼짐(대조) | 민법 105 | 기본 경로 answer |

W7의 추가 근거(90001 판단 1문단)는 종료 뒤 차임 의무만 다루고 특약 적용 범위는 다루지 않는다.

## 해석 기준
