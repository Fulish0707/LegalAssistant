## 2. 리뷰 지적과 수정

범위는 `webapp/`, `src/legal_rag/`, `scripts/serve.py`다. 파일 업로드 처리, 로그인·세션 쿠키 설정, 평가 스크립트는 깊게 보지 않았다.

| 지적 | 확인 방법 | 수정 |
| --- | --- | --- |
| 잘못된 인용 하나를 지울 때 "제3조"가 "제3조의2"가 든 문장까지 지운다 | 코드 | 조 번호 뒤에 "의 숫자"가 오면 맞지 않는 것으로 본다. 다른 법령의 같은 조 번호는 여전히 같이 지워진다 |
| 4,000자가 넘는 질문이 "서비스 장애"로 표시되고 하루 사용량이 줄어든다 | 코드 | 웹 앱이 길이를 먼저 확인하고 안내한다. 사건 자료 이름은 200자로 자른다 |
| "안녕" 같은 정해진 답에도 하루 사용량이 줄어든다 | 코드 | 정해진 답은 사용량을 쓰지 않는다 |
| 같은 대화에 동시에 쓰면 500 오류가 날 수 있다 | 코드 | 다음 번호를 한 SQL 문에서 정한다 |
| 동시 요청 사이에 검색 추적 정보가 섞인다 | 코드 | 추적 정보를 스레드마다 둔다 |
| 지운 상담의 번호가 다시 쓰인다. 백엔드는 새 상담을 지운 대화의 연속으로 답한다 | 테스트로 재현 | 이 브라우저가 쓴 가장 큰 번호보다 큰 번호로 연다 |
| 긴 문서를 분석하면 앞부분과 지시문이 말없이 잘린다 | 실제 Ollama로 재현 | 앞 8,000자만 분석하고 알린다 (3절) |
| 서버 시작 직후 요청 하나가 모든 요청을 멈춘다 | 테스트로 재현 | 검색기를 기다리는 호출을 스레드풀로 옮겼다 |
| 고정한 사건이 8개를 넘으면 최근 것이 먼저 밀려난다 | 테스트로 재현 | 순서가 보존되는 목록으로 저장한다 |
| 조 번호만 맞으면 다른 법령의 인용도 통과한다 | 측정 (4절) | 고치지 않는다 |

상담 번호와 고정 사건 문제는 같은 브라우저 안에서만 일어난다. 백엔드의 대화 ID에 브라우저마다 다른 ID가 들어가므로 다른 사용자의 대화는 섞이지 않는다.

## 3. 긴 문서 분석

서빙 설정에서 모델의 입력 한도는 12,288토큰이다. Ollama는 이 한도를 넘는 프롬프트의 앞부분을 버린다. 계약금(제1조)과 위약금(마지막 조)을 묻는 합성 계약서로 측정했다.

| 문서 길이 | 모델이 받은 토큰 | 답변에 제1조의 금액 |
| ---: | ---: | --- |
| 4,490자 | 4,098 | 있음 |
| 14,369자 | 10,662 | 있음 |
| 17,315자 | 6,146 (잘림) | 없음. "계약금은 명시되지 않았다"고 답함 |
| 34,955자 | 6,146 (잘림) | 없음 |

실제 판례와 법령은 글자당 0.66~0.75토큰이다. 그래서 8,000자로 자르면 지시문과 출력까지 한도 안에 든다. 수정 뒤 34,955자 문서: 입력 6,420토큰, 출력 최대 1,652토큰, 6회 모두 제1조의 금액을 찾았다. 그러나 5회는 같은 답변에서 위약금이 "문서에서 명시되지 않았다"고 썼다. 그래서 보고서 맨 위에 잘린 사실을 알린다.

## 4. 법령 이름까지 맞는 인용만 통과

**문제.** 근거에 "주택임대차보호법 제3조"가 있으면, 답변의 "민법 제3조"도 검증을 통과한다. 검증기는 조 번호만 따로 근거 목록에 넣기 때문이다.

**바꾼 것.** 법령 이름이 붙은 인용은 같은 법령의 같은 조가 근거에 있어야 통과한다. 법령 이름이 없는 인용은 예전처럼 통과한다.

**통과 기준 (실행 전에 정함).** 잡아낸 실제 오류가 잘못된 표시 이상이어야 한다. 그리고 잘못된 표시가 붙은 답변이 2% 이하여야 한다.

| 질문 세트 | 답변 | 실제 오류 | 잘못된 표시 | 판정 |
| --- | ---: | ---: | ---: | --- |
| 최종 테스트 274문항 | 274 | 0 | 5 | 미달 |
| 개발 80문항, 저장된 20회분 | 1,599 | 6 (답변 8개, 0.5%) | 20 (답변 51개, 3.2%) | 미달 |

실제 오류의 예: 근거는 관세법 제165조의5인데 답변은 관세사법 제165조의5. 근거는 법인세법 제59조의2인데 답변은 소득세법 제59조의2. 근거는 아동복지법 시행령 제2조인데 답변은 아동복지법 제2조.

잘못된 표시 20개 중 16개는 근거를 읽는 방식에서 생겼다.

- 법령 이름과 조 사이의 괄호, 예: "구 지방세법(… 개정되기 전의 것) 제29조" (10개)
- "(이하 '제주특별법'이라 함)" 같은 정의된 약칭 (3개)
- 판례가 법령 이름 없이 본문을 인용한 경우 (3개)

다시 시도하려면 이 세 가지를 먼저 고친다. 그다음 두 세트 모두 쓰지 않은 질문으로 새 답변을 만들어 판정해야 한다. 바꾼 코드는 로컬 브랜치 `fix/law-aware-citations`에 기록으로 남겼다.

## 5. Ollama 0.40.4

2026-10-14 업데이트 뒤 Ollama가 모든 모델을 불러오지 못했다. 원인은 업데이트되지 않은 옛 라이브러리와, 직접 빌드해 넣은 `llama-server`의 충돌이었다. 공식 설치를 다시 해서 고쳤다.
