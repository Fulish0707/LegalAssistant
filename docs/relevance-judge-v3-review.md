# 관련성 Judge 1·2차 비교와 3차 수정 근거

당시 검토 결과를 보관한 기록이다. 현재 채점 설정과 명령은
[Corpus relevance prompts](corpus-relevance-prompts.md), 전체 안내는
[평가 문서 목차](evaluation-index.md)를 참고한다.

대상은 ip-v1-pilot-200의 동일 50쌍이다. calibration.csv의 기준 등급은 AI가 작성했으며 독립적인 사람 검증이 아니다. 기준 라벨과 기존 실행 결과는 변경하지 않았다.

## 입력 확인

CSV의 chunk_text·reference_answer는 pool.jsonl의 실제 입력과 50쌍 모두 일치한다. 조각 최대 길이는 3,487자, 답변은 191자다. 따라서 3,500자/800자 제한으로 추가 절단된 사례는 0개다. 원래 조각의 중간 시작·종료와 모델의 문맥 해석 실패는 별개다. 실제 모델 토큰화에 따른 컨텍스트 처리까지 이번 검사로 검증한 것은 아니다.

## 점수 변화

1차→2차 전이는 0→0 8개, 0→1 6개, 1→1 15개, 1→2 9개, 2→2 12개다. 변경된 15개 모두 상향됐고, 기준과 비교하면 정답화 4개, 오답화 10개, 계속 불일치 1개다. 정확 일치율은 56%→44%, 가중 κ는 0.4455→0.3363, 이진 2점 κ는 0.3421→0.3455다.

## 검토 사례

아래 번호는 CSV 헤더를 제외한 데이터 행 번호다.

- 9·11·13·38·41·42·48행: 이유에서는 핵심 법리가 없다고 설명하면서 1점을 부여한다. 근거 존재 여부를 충분성보다 먼저 판정하고 출력 등급과 이유를 대조하도록 수정했다.
- 8·35행: 피청구인의 사용 증명 의무를 청구인의 불사용 입증으로 바꿔 읽는다. 주체·입증책임·부정어를 명시적으로 대조하도록 했다.
- 14·15행: 개별 사건의 불인정 결론을 일반 법리와의 충돌로 오인한다. 일반 기준과 해당 사건의 적용 결과를 구별하도록 했다.
- 17행: 당사자 주장에 나타난 법리를 채택된 판단처럼 평가한다. 발화 주체와 판단 부분 구분을 유지했다.
- 24·44행: 유사한 표현을 근거로 다른 요건·절차를 동일시한다. 조문 번호 차이와 실질적인 규율 대상 차이를 구별하도록 했다.
- 39행: 일부 정정사유와 제한은 있으나 참조답변이 열거한 범위를 모두 설명하지 않는다. 요건 전체 질문과 독립 사유의 예시 질문을 구별하도록 했다.
- 20·30·45·46행: 기존 1점이 기준 2점으로 개선됐다. 표현·인용번호가 달라도 완결된 핵심 법리의 근거를 인정하는 규칙은 유지한다.

위 사례 분류는 제공된 텍스트의 비교이며 현행 법률 정확성 검증이 아니다. 특히 참조답변 오류와 부분 근거의 충분성에 관한 기준 AI 라벨도 사람의 재검토 대상이다.

## 변경과 검증

프롬프트 전문은 relevance-judge-prompt-v3.md에 있다. 시스템 1,991자, 입력 템플릿 포함 2,164자로 3,500자 이내다. 실제 질문·참조답변·조각의 길이는 이 지시문 예산과 별개다.

실제 입력에 제공/원문 문자 수와 종료 경계를 표시한다. 길이가 같아도 조각 자체의 경계 누락은 있을 수 있으며, 생략된 내용을 복원하지 않는다. 잘림만으로 자동 감점하지 않고 보이는 근거의 충분성으로 평가한다. 참조답변의 잘림 때문에 요구사항을 확정할 수 없으면 2점을 주지 않도록 했다.

기존 길이 제한·모델·생성 설정·출력 스키마는 유지했다. 새 해시는 b733e2805288462760ae16c335f4640a4db1fac4be4fcb2b24c61abc3a26ab0f다. 관련 테스트 27개가 통과했다. 3차 모델 실행 및 개선 여부 측정은 아직 하지 않았다. 동일 표본에서 통과해도 별도 사람 검토 표본으로 검증해야 한다.
