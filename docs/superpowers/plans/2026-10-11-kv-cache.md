# KV 캐시 시험 계획

사용자 승인: 다음 테스트. execute-protocol의 격리 상태와 원본 보존 기준을 적용한다. 직접 실행하며 운영 설정은 수정하지 않는다.

1. **T1 — 고정**: 원본·이전 상태·모델 해시를 기록한다. 입력 7개, 동일 paired 요청, 실행 코드와 기준을 inference 전에 고정한다.
2. **T2 — 측정 및 검토**: 별도 서버를 4개 블록으로 실행한다. 측정 24회와 예열 4회를 기록한다. 12쌍을 전체 근거와 비교한다. 모든 요청과 최종 정책을 오프라인 재생한다.
3. **T3 — 결과 및 감사**: 지연, 디코딩 속도, 메모리, 품질을 따로 보고한다. 원본 코드·모델·이전 상태 보존, 종료 정리, 문서 경로를 감사하고 상태를 완료한다.

설계: [KV 캐시 시험 설계](../specs/2026-10-11-kv-cache-design.md).

## 실행 결과

- 측정 24회와 예열 4회를 완료했다. 12쌍은 AI reviewed (Codex) 이유와 원본 해시를 연결했다.
- 속도와 품질 기준은 실패했다. 입력 보존은 통과했다. 후보는 적용하지 않는다.
- 모든 36호출과 기존 최종 정책의 오프라인 재생은 통과했다.
- [상세 결과](../../experiments/kv-cache-2026-10-11.md)를 기록했다. 최종 감사와 상태 완료는 canonical 실행 상태에 기록한다.
