# 보안 수정 계획

기준: `docs/security-review-2026-10-07.md`의 S01–S15. 사용자의 `proceed`로 구현을 진행한다.

1. Flask의 디버그·세션·CSRF·입력·요청량 제한을 적용한다.
2. 내부 API에 서비스 인증, 워크스페이스 격리, 동시 처리 제한을 적용한다.
3. 채팅을 단일 POST 스트리밍으로 바꾸고 양쪽 대화 기록 삭제를 연결한다.
4. 파일 크기·서명·압축·페이지·추출량을 제한하고 제한된 별도 프로세스에서 파싱한다.
5. 추적 정보와 오류 응답을 축소한다. Qdrant를 로컬 바인딩과 키 인증으로 설정한다.
6. 정적 검사를 진행하고 적용 조건·남은 운영 작업을 문서에 기록한다.

기존 README와 실제 데이터·비밀키는 보존한다. 배포, 서버 재시작, 키 교체, 커밋은 수행하지 않는다.
회귀 테스트의 추가·실행은 사용자의 명시적 요청이 있을 때 진행한다.
